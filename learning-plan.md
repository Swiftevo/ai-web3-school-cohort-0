# AI x Web3 School Learning Plan

This plan is tuned for a learner with AI / Web3 / programming foundations, at least one hour per day, Traditional Chinese output preference, and a likely Hackathon goal.

## Learning Map

The Handbook is organized into four layers:

1. AI fundamentals: LLM, Prompt, Context, RAG, Agent, Frameworks, MCP, Evaluation.
2. Web3 fundamentals: Network, Cryptography, Wallet, Smart Contract, Account Abstraction, DeFi, Oracle, Indexing, Security.
3. AI x Web3 Bridge: Chain-aware Context, Web3 Tool Use, Agent Workflow, Agent Wallet, Machine Payment, Settlement & Escrow, Agent Identity, Trust & Reputation, Verifiable AI, AI Security, AI Privacy, Governance AI.
4. Frontier tracks: Agentic Commerce, Wallet / Permission, AI Security, Governance, Dev Tooling, Open Track.

## Week 1: Shared Language

Goal: build shared vocabulary across AI, Web3, and the bridge layer, while keeping notes public and reusable.

- Day 1: Handbook overview, profile confirmation, repo setup, first check-in.
- Day 2: LLM + Prompt. Output: one prompt rewrite with clear goal, boundary, and format.
- Day 3: Context + RAG. Output: one sourced answer with `answer`, `sources`, `uncertainties`, `needs_version_check`.
- Day 4: Agent + Tool Use. Output: one workflow diagram or step list with human check points.
- Day 5: Network + Wallet. Output: transaction lifecycle notes and fields an Agent must read from tools.
- Day 6: Smart Contract + Account Abstraction. Output: permission model notes.
- Day 7: Weekly review. Output: one public learning summary and 1-3 Handbook feedback items.

## Week 2: Bridge Practice

Goal: connect AI workflow design with wallet, permissions, and chain-aware context.

- Chain-aware Context: decide which chain fields are evidence, which are model summaries.
- Web3 Tool Use: define RPC, wallet, explorer, and contract call tool boundaries.
- Agent Workflow: mark automated steps, confirmation steps, and forbidden steps.
- Agent Wallet: draft a policy for session keys, limits, expiry, and revocation.
- AI Security: identify prompt injection, tool abuse, permission expansion, and audit log risks.

## Week 3: Prototype Direction

Pick one Hackathon-leaning track:

- Transaction explainer: LLM + Context + Chain-aware Context.
- Chain Agent: Agent + Web3 Tool Use + Agent Workflow.
- Wallet automation: Wallet + Account Abstraction + Agent Wallet.
- Security or risk control: Prompt + RAG + AI Security.
- Governance assistant: Governance AI + RAG + Verifiable AI.

## Hackathon Preparation

- Maintain a running idea list in `hackathon/`.
- For each idea, write: user, pain point, why AI x Web3, minimum demo, required data/tools, wallet or contract touchpoints, and risks.
- Prefer demos that can be shown in 3 minutes and explained in one sentence.
- Keep the first prototype small: one user flow, one chain interaction or verifiable record, one clear AI contribution.

## Daily Minimum: 60 Minutes

- 10 minutes: open WCB Learning and confirm today's official task/check-in entry.
- 20 minutes: read one Handbook node and record source links.
- 20 minutes: produce one small artifact: note, prompt, workflow, diagram, policy, demo snippet, or feedback item.
- 10 minutes: update `daily/YYYY-MM-DD.md` and draft check-in.

If time expands beyond one hour, use the extra time for Hackathon idea refinement or prototype experiments.

## Weekly Proof-of-Work

- One public note or mini demo.
- One refined task note.
- One Handbook feedback item, even if small.
